# Java 代码笔记

用于记录 Java 算法题、数据结构实现和日常练习代码。

## 目录

| 文件 | 内容 |
| --- | --- |
| `3. 无重复字符的最长子串.java` | 滑动窗口求无重复字符的最长子串 |
| `FindKthLargest.java` | 查找数组中的第 K 个最大元素 |
| `LRUCache.java` | LRU 缓存实现 |
| `MeetingRoundsSolver.java` | 会议轮次问题 |
| `ReverseKGroup.java` | K 个一组反转链表 |
| `ReverseList.java` | 反转链表 |

## 运行方式

进入代码所在目录后，编译并运行对应文件：

```bash
javac ReverseKGroup.java
java ReverseKGroup
```

部分文件包含 `main` 方法，可直接运行其中的测试用例。
